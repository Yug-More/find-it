# Sprint 4: final integration

FindIt — CS 160 Software Engineering, San José State University.

## Goal

Demonstrate account access, lost/found reporting, search, matching, ownership claims,
owner decisions, resolved history, and in-app notifications with reproducible setup.

## Team

- Yug More: mobile frontend, integration, testing, documentation.
- Marl Jonson: backend and API development.
- Brody Smith: database, Supabase configuration, testing, documentation.

## Deliverables and result

The existing report, claim, notification, storage, and admin implementations are
preserved. Sprint 4 adds matching eligibility checks, session restoration recovery,
stale-response protection, upload byte validation, realistic demo history, regression
coverage, and credential-free CI. Approval continues to resolve the report; no new
persisted status values or schema migration are introduced.
